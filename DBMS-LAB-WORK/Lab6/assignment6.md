# Assignment 6: Sorting Rows and Removing Repeats

# Aim

To sort records in a database table and remove duplicate values from query results using ORDER BY and DISTINCT.

# Problem Statement

Create a product table containing product names, categories and prices. Retrieve product information by sorting prices, displaying unique categories and selecting products according to their prices.

# Theory:

SQL provides different clauses to arrange and retrieve records from a table.
1. `ORDER BY` – Used to sort records in ascending or descending order.
2. `DISTINCT` – Used to display unique values and remove repeated values.
3. `DESC` – Used to sort records from highest to lowest.
4. `ASC` – Used to sort records alphabetically or from lowest to highest.
5. `LIMIT` – Used to display only a specified number of records.

# Tasks

**Task 1: Sort Products by Price**

- Retrieve all products from the product table.
- Arrange the products in descending order of price.
- Display the highest-priced products first.

**Task 2: Display Unique Categories**

- Retrieve all distinct product categories.
- Remove repeated category values from the result.
- Display the categories in sorted order.

**Task 3: Display Two Highest-Priced Products**

- Retrieve the two products having the highest prices.
- Arrange the results in descending order of price.
- Display only two records.

# Objectives

- To understand the ORDER BY clause.
- To sort records in ascending and descending order.
- To remove duplicate values using DISTINCT.
- To retrieve a limited number of records.
- To understand sorting and filtering techniques.
