# Assignment 1: Creating a Table and Adding Rows

# Aim

To create a student table, insert multiple records into it and display all the stored records.

# Problem Statement

Create a table named "student" containing roll number, name and marks. Insert three student records using a single INSERT operation and display the complete table.

# Tasks

**Task 1: Create a Student Table**

Create a table named "student" with the following three columns:

- roll_no: Stores the student's roll number as a whole number.
- name: Stores the student's name with a maximum length of 30 characters.
- marks: Stores the student's marks as a whole number.

**Task 2: Insert Student Records**

Insert the following three student records into the student table using a single INSERT statement:

- Roll Number: 101, Name: Asha, Marks: 78
- Roll Number: 102, Name: Rohan, Marks: 64
- Roll Number: 103, Name: Neha, Marks: 88

**Task 3: Display Student Records**

Retrieve and display all columns and all rows from the student table to verify that the records have been inserted successfully.

# Objectives

- To understand table creation in SQL.
- To learn how to define columns and data types.
- To insert multiple records in a single operation.
- To retrieve complete information from a table.

# Concepts Used

- CREATE TABLE
- INSERT INTO
- SELECT
- Data Types

# Conclusion

Successfully created the student table, inserted three student records using a single INSERT statement and displayed all the records.
